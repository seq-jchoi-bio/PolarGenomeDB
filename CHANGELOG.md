# Changelog

User-facing changes to Polar Genome DB. Dates indicate change records, not
necessarily deployment or GitHub publication dates.

## Beta 1.0.1 - 2026-10-05

- Updated the privacy policy.
- Prepared source code for public release.
- Added system context and container architecture diagrams.
- Updated the Home version badge and release notes.
- Licensed original source code and technical documentation under MIT, with
  separate notices for images and third-party materials.

## Beta 1.0.0 - Initial Beta Baseline

- Multi-species genome exploration for Cq and Da.
- Genome browsing, gene search, sequence search and similar-gene analysis.
- GO enrichment, semantic GO and PCR primer design.
- Expression, protein-domain and phylogenetic visualizations.
- Result exports, a gene basket and supporting resource pages.
